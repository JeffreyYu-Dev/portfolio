# Mail App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An Apple Mail–style window, opened from the dock, that shows seeded emails from Jeffrey and lets a visitor send him a real message through Resend, plus a `/contact` page with the same form for phones.

**Architecture:** Pure, unit-tested modules hold everything that can break quietly: the Zod schema (`mail-schema.ts`), the send logic with spam checks (`send-mail.ts`), the visitor's saved state (`mail-store.ts`), the window state (`window-store.ts`) and two formatting helpers. A thin TanStack Start server function wraps the send logic with the real Resend client, so `resend` and the API key stay on the server. The React pieces (`AppWindow`, `Compose`, `MailApp`, `/contact`) only wire those modules to the screen.

**Tech Stack:** TanStack Start 1.168 / Router 1.170, React 19, Tailwind v4, lucide-react, Zod 4, Resend 6, Vitest 5, npm.

**Spec:** `docs/superpowers/specs/2026-10-13-mail-app-design.md`

## Global Constraints

- New runtime dependencies: `zod` (^4) and `resend` (^6) only.
- `RESEND_API_KEY` is already in `.env`. `MAIL_TO` defaults to `jeffrey.yu.w@gmail.com`, and `MAIL_FROM` defaults to `Portfolio <onboarding@resend.dev>`. Read them from `process.env` at call time.
- `resend` and `process.env` may only be imported or used in `src/server/send-mail.ts`. Neither may reach the client bundle (checked in Task 9).
- Server function validator: use `.validator(...)`. In the installed `@tanstack/start-client-core`, `inputValidator` is marked deprecated in favour of `validator`. (The spec left this to be checked.)
- Field limits: name 1–100, email up to 254 and a valid address, subject 0–200 (empty becomes `(no subject)`), body 1–5000 after trimming. CR/LF in name and subject collapse to one space.
- Spam: a non-empty honeypot `website`, or under `3000`ms since `openedAt`, returns `{ ok: true }` without sending.
- Email sent: `to` MAIL_TO, `from` MAIL_FROM, `replyTo` the visitor, subject `[portfolio] <subject>`, and text equal to the body, a blank line, then `— <name> <email>`.
- Failure copy, verbatim: `Couldn't send. Try again, or email me directly at jeffrey.yu.w@gmail.com`
- localStorage key `mail:v1`. Sent is capped at 20, newest first. The draft saves 500ms after the last keystroke, and an all-empty draft is stored as `null`.
- Window: about 900×560, centred, hidden below `md`. Red closes it, yellow and green do nothing. `role="dialog"`, non-modal, Esc closes it. **No open/close animation or new transitions** (Jeffrey wants minimal motion).
- Match repo style: **2-space indentation**, short lowercase comments that explain *why*, `#/` import alias. Do **not** run `biome format --write` (`biome.json` says tabs, but the code uses spaces). Lint only the files you touched with `npx biome lint <files>`.
- Baselines: `npx tsc --noEmit` already reports 4 `TS6133` unused-variable errors in `src/data/work.ts` and `src/routes/index.tsx`. Leave them alone, and add no new errors. `npm test` currently passes 30 tests.
- Vitest runs in Node (no DOM) and only picks up `src/**/*.test.ts`. Keep logic in `.ts` modules so it can be tested.
- Commit after every task, staging only that task's files. End each commit message with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **A visitor reopens a saved draft and hits Send within 3 seconds.** A human must never be silently dropped by the timing check. The draft keeps its original `startedAt`, and compose sends that as `openedAt`. Pinned in Task 2 (an old `openedAt` sends) and Task 4 (`startedAt` survives draft updates).
2. **The 500ms draft save fires after a successful send** and brings the cleared draft back. `recordSent` cancels any pending save. Pinned in Task 4 with fake timers.
3. **Pasted multi-line names and subjects, and whitespace-only bodies or names.** Line breaks collapse, and whitespace-only input is rejected with the field's message. Pinned in Task 1.
4. **localStorage from an older or hand-edited shape** (missing keys, wrong types, invalid JSON) must load as an empty state, not crash the dock badge. Pinned in Task 4.
5. **Seeded emails dated in the future, or across a year boundary**, still get a sensible label (no "-1 days" and no wrong weekday). Pinned in Task 3.

`src/lib/mail-schema.ts`:
```ts
import { z } from "zod";

// one schema for the compose form and the server function, so the rules can't drift.
// line breaks in single-line fields would let someone add their own mail headers
const oneLine = (s: string) => s.replace(/[\r\n]+/g, " ").trim();

export const mailSchema = z.object({
  name: z
    .string()
    .transform(oneLine)
    .pipe(
      z.string().min(1, "Add your name").max(100, "That name's a bit long"),
    ),
  email: z
    .string()
    .trim()
    .pipe(
      z
        .email("Add your email so I can reply")
        .max(254, "That email's a bit long"),
    ),
  subject: z
    .string()
    .transform(oneLine)
    .pipe(z.string().max(200, "Keep the subject under 200 characters"))
    .transform((s) => s || "(no subject)"),
  body: z
    .string()
    .trim()
    .min(1, "Write me something")
    .max(5000, "Keep it under 5000 characters"),
});

// what the server function receives: the form plus the two spam signals
export const sendSchema = mailSchema.extend({
  website: z.string().optional(),
  openedAt: z.number(),
});

export type MailFields = z.input<typeof mailSchema>;
export type Mail = z.output<typeof mailSchema>;
export type SendInput = z.output<typeof sendSchema>;
export type FieldErrors = Partial<Record<keyof MailFields, string>>;

export function checkMail(
  fields: MailFields,
): { ok: true; mail: Mail } | { ok: false; errors: FieldErrors } {
  const result = mailSchema.safeParse(fields);
  if (result.success) return { ok: true, mail: result.data };
  const errors: FieldErrors = {};
  // first message per field, that's all the form shows
  for (const [key, messages] of Object.entries(
    z.flattenError(result.error).fieldErrors,
  )) {
    if (messages?.[0]) errors[key as keyof MailFields] = messages[0];
  }
  return { ok: false, errors };
}
```

`src/lib/send-mail.ts`:
```ts
import { socials } from "#/data/socials";
import type { SendInput } from "#/lib/mail-schema";

export type Outgoing = {
  to: string;
  from: string;
  replyTo: string;
  subject: string;
  text: string;
};
// rejects when the email didn't go out
export type Sender = (mail: Outgoing) => Promise<void>;
export type SendResult = { ok: true } | { ok: false; message: string };

export const SEND_FAILED = `Couldn't send. Try again, or email me directly at ${socials.email}`;
// people take longer than this to write anything. bots usually don't
export const MIN_FILL_MS = 3000;

export async function handleSend(
  input: SendInput,
  deps: { send: Sender | null; now: () => number; to: string; from: string },
): Promise<SendResult> {
  // a caught bot gets the same answer as a person, so it learns nothing
  if (input.website || deps.now() - input.openedAt < MIN_FILL_MS) {
    return { ok: true };
  }
  if (!deps.send) {
    console.error("send-mail: RESEND_API_KEY is not set");
    return { ok: false, message: SEND_FAILED };
  }
  try {
    await deps.send({
      to: deps.to,
      from: deps.from,
      replyTo: input.email,
      subject: `[portfolio] ${input.subject}`,
      text: `${input.body}\n\n— ${input.name} <${input.email}>`,
    });
    return { ok: true };
  } catch (error) {
    console.error("send-mail: couldn't send", error);
    return { ok: false, message: SEND_FAILED };
  }
}
```

import { createServerFn } from "@tanstack/react-start";
import { Resend } from "resend";
import { socials } from "#/data/socials";
import { sendSchema } from "#/lib/mail-schema";
import { handleSend, type Sender } from "#/lib/send-mail";

// the only place resend and the key are touched. the start compiler swaps this
// handler for a fetch on the client, so neither ends up in the browser bundle
export const sendMail = createServerFn({ method: "POST" })
  .validator(sendSchema)
  .handler(({ data }) => {
    const key = process.env.RESEND_API_KEY;
    return handleSend(data, {
      send: key ? resendSender(key) : null,
      now: Date.now,
      to: process.env.MAIL_TO || socials.email,
      // resend's shared sender only delivers to the account owner, which is me
      from: process.env.MAIL_FROM || "Portfolio <onboarding@resend.dev>",
    });
  });

function resendSender(key: string): Sender {
  const resend = new Resend(key);
  return async (mail) => {
    // resend returns its errors rather than throwing them
    const { error } = await resend.emails.send(mail);
    if (error) throw new Error(`${error.name}: ${error.message}`);
  };
}
```

const MONTHS = ["Jan", "Feb", "Mar", "Apr", "May", "Jun", "Jul", "Aug", "Sep", "Oct", "Nov", "Dec"];

// how mail labels a message: the time today, then Yesterday, then the weekday for
// the past week, then the date. formatted by hand because Intl's spacing before
// AM/PM differs between node versions
export function mailDate(iso: string, now = new Date()): string {
  const date = new Date(iso);
  const days = Math.round((startOfDay(now) - startOfDay(date)) / 86_400_000);
  if (days === 0) {
    const h = date.getHours();
    const m = String(date.getMinutes()).padStart(2, "0");
    return `${h % 12 || 12}:${m} ${h < 12 ? "AM" : "PM"}`;
  }
  if (days === 1) return "Yesterday";
  if (days > 1 && days < 7) return DAYS[date.getDay()];
  return `${MONTHS[date.getMonth()]} ${date.getDate()}`;
}

// round() above absorbs the hour lost or gained across daylight saving
function startOfDay(d: Date) {
  return new Date(d.getFullYear(), d.getMonth(), d.getDate()).getTime();
}

export type Piece = { text: string } | { href: string };

const URL = /https?:\/\/[^\s<>"]+[^\s<>".,;:!?)\]'"]/g;

// emails are plain text so they're easy to write. blank lines split paragraphs
// and bare links become clickable
export function paragraphs(body: string): Piece[][] {
  return body
    .replace(/\r\n?/g, "\n")
    .split(/\n\s*\n/)
    .map((p) => p.trim())
    .filter(Boolean)
    .map(linkify);
}

function linkify(text: string): Piece[] {
  const pieces: Piece[] = [];
  let last = 0;
  for (const match of text.matchAll(URL)) {
    if (match.index > last) pieces.push({ text: text.slice(last, match.index) });
    pieces.push({ href: match[0] });
    last = match.index + match[0].length;
  }
  if (last < text.length) pieces.push({ text: text.slice(last) });
  return pieces;
}

import { useSyncExternalStore } from "react";

// what a visitor has done in mail: which emails they've opened, what they've sent
// me and an unsent draft. kept in their browser only, replies go to their real inbox
export type SentEmail = { id: string; subject: string; body: string; date: string };
export type Draft = {
  name: string;
  email: string;
  subject: string;
  body: string;
  // when they started writing it. sent as the spam check's start time, so
  // reopening an old draft and sending straight away isn't mistaken for a bot
  startedAt: number;
};
export type MailState = { read: string[]; sent: SentEmail[]; draft: Draft | null };

export const STORAGE_KEY = "mail:v1";
export const DRAFT_DELAY_MS = 500;
const MAX_SENT = 20;

export const emptyMail: MailState = { read: [], sent: [], draft: null };

export function newDraft(now = Date.now()): Draft {
  return { name: "", email: "", subject: "", body: "", startedAt: now };
}

// --- pure updates ---

export function withRead(state: MailState, id: string): MailState {
  if (state.read.includes(id)) return state;
  return { ...state, read: [...state.read, id] };
}

export function withSent(state: MailState, email: SentEmail): MailState {
  return { ...state, sent: [email, ...state.sent].slice(0, MAX_SENT), draft: null };
}

export function withDraft(state: MailState, draft: Draft | null): MailState {
  const empty =
    !draft || [draft.name, draft.email, draft.subject, draft.body].every((f) => !f.trim());
  return { ...state, draft: empty ? null : draft };
}

export function unreadCount(state: MailState, ids: string[]) {
  return ids.filter((id) => !state.read.includes(id)).length;
}

// whatever is in storage may be from an older version or hand-edited,
// so keep only the parts that still have the right shape
export function parseStored(raw: string | null): MailState {
  let data: unknown;
  try {
    data = JSON.parse(raw ?? "");
  } catch {
    return emptyMail;
  }
  if (!isRecord(data)) return emptyMail;
  return {
    read: Array.isArray(data.read)
      ? data.read.filter((id): id is string => typeof id === "string")
      : [],
    sent: Array.isArray(data.sent) ? data.sent.filter(isSent).slice(0, MAX_SENT) : [],
    draft: isDraft(data.draft) ? data.draft : null,
  };
}

const isRecord = (v: unknown): v is Record<string, unknown> =>
  typeof v === "object" && v !== null && !Array.isArray(v);

const isSent = (v: unknown): v is SentEmail =>
  isRecord(v) && ["id", "subject", "body", "date"].every((k) => typeof v[k] === "string");

const isDraft = (v: unknown): v is Draft =>
  isRecord(v) &&
  ["name", "email", "subject", "body"].every((k) => typeof v[k] === "string") &&
  typeof v.startedAt === "number";

// --- the store ---

let state = emptyMail;
let loaded = false;
let pending: ReturnType<typeof setTimeout> | undefined;
let pendingDraft: Draft | null = null;
const listeners = new Set<() => void>();

// read lazily on first use, after hydration, so the server render and the
// first client render agree (everything unread, nothing sent)
function load() {
  if (loaded || typeof localStorage === "undefined") return;
  loaded = true;
  try {
    state = parseStored(localStorage.getItem(STORAGE_KEY));
  } catch {
    // storage blocked (private mode, permissions). mail still works for the visit
  }
}

function set(next: MailState) {
  if (next === state) return;
  state = next;
  try {
    localStorage.setItem(STORAGE_KEY, JSON.stringify(state));
  } catch {
    // full or blocked, same as above
  }
  for (const listener of listeners) listener();
}

export function getMail() {
  load();
  return state;
}

export function markRead(id: string) {
  set(withRead(getMail(), id));
}

// called on every keystroke, so it waits for a pause before writing
export function saveDraft(draft: Draft) {
  pendingDraft = draft;
  clearTimeout(pending);
  pending = setTimeout(flushDraft, DRAFT_DELAY_MS);
}

export function flushDraft() {
  clearTimeout(pending);
  pending = undefined;
  if (!pendingDraft) return;
  const draft = pendingDraft;
  pendingDraft = null;
  set(withDraft(getMail(), draft));
}

export function recordSent(email: SentEmail) {
  // a save still waiting would otherwise bring the draft back after sending
  clearTimeout(pending);
  pending = undefined;
  pendingDraft = null;
  set(withSent(getMail(), email));
}

function subscribe(listener: () => void) {
  listeners.add(listener);
  return () => {
    listeners.delete(listener);
  };
}

export function useMail() {
  return useSyncExternalStore(subscribe, getMail, () => emptyMail);
}

// false on the server and during hydration, true once saved state is readable
export function useMailReady() {
  return useSyncExternalStore(subscribe, () => true, () => false);
}
```

import { useSyncExternalStore } from "react";

// which app windows are open and which is in front. phase 3 adds position, size
// and minimizing to this same store (see the macos desktop spec)
export type AppId = "mail";
export type Win = { id: AppId; open: boolean; z: number };
export type Windows = Record<AppId, Win>;

export const initialWindows: Windows = {
  mail: { id: "mail", open: false, z: 0 },
};

export function focused(state: Windows, id: AppId): Windows {
  const others = Object.values(state).filter((w) => w.id !== id);
  const top = Math.max(0, ...others.map((w) => w.z));
  // already in front: same state, so repeated clicks don't re-render or climb forever
  if (state[id].z > top) return state;
  return { ...state, [id]: { ...state[id], z: top + 1 } };
}

export function opened(state: Windows, id: AppId): Windows {
  const open = state[id].open ? state : { ...state, [id]: { ...state[id], open: true } };
  return focused(open, id);
}

export function closed(state: Windows, id: AppId): Windows {
  if (!state[id].open) return state;
  return { ...state, [id]: { ...state[id], open: false } };
}

let state = initialWindows;
const listeners = new Set<() => void>();

function set(next: Windows) {
  if (next === state) return;
  state = next;
  for (const listener of listeners) listener();
}

export function openWindow(id: AppId) {
  set(opened(state, id));
}

export function closeWindow(id: AppId) {
  set(closed(state, id));
}

export function focusWindow(id: AppId) {
  set(focused(state, id));
}

export function useWindow(id: AppId) {
  return useSyncExternalStore(
    (listener) => {
      listeners.add(listener);
      return () => {
        listeners.delete(listener);
      };
    },
    () => state[id],
    // the server always renders windows closed
    () => initialWindows[id],
  );
}

import { socials } from "#/data/socials";
import { type Draft, flushDraft, recordSent, saveDraft, type SentEmail } from "#/lib/mail-store";
import { checkMail, type FieldErrors, type MailFields } from "#/lib/mail-schema";
import { SEND_FAILED } from "#/lib/send-mail";
import { sendMail } from "#/server/send-mail";
import { Send } from "lucide-react";
import { type FormEvent, type ReactNode, useEffect, useId, useRef, useState } from "react";

// a new message to me. the draft is saved as they type, so closing the window or
// a failed send never loses what they wrote
export function Compose({
  initial,
  onSent,
  onCancel,
}: {
  initial: Draft;
  onSent: (sent: SentEmail, replyTo: string) => void;
  onCancel?: () => void;
}) {
  const [fields, setFields] = useState<MailFields>({
    name: initial.name,
    email: initial.email,
    subject: initial.subject,
    body: initial.body,
  });
  const [errors, setErrors] = useState<FieldErrors>({});
  const [sending, setSending] = useState(false);
  const [failed, setFailed] = useState(false);
  const honeypot = useRef<HTMLInputElement>(null);
  const id = useId();

  // closing mid-sentence still keeps the last few keystrokes
  useEffect(() => flushDraft, []);

  const change = (key: keyof MailFields) => (value: string) => {
    const next = { ...fields, [key]: value };
    setFields(next);
    setErrors((e) => ({ ...e, [key]: undefined }));
    saveDraft({ ...next, startedAt: initial.startedAt });
  };

  async function send(e: FormEvent) {
    e.preventDefault();
    const checked = checkMail(fields);
    if (!checked.ok) {
      setErrors(checked.errors);
      return;
    }
    setSending(true);
    setFailed(false);
    try {
      const result = await sendMail({
        data: {
          ...fields,
          website: honeypot.current?.value ?? "",
          openedAt: initial.startedAt,
        },
      });
      if (!result.ok) {
        setFailed(true);
        return;
      }
      const sent = {
        id: crypto.randomUUID(),
        subject: checked.mail.subject,
        body: checked.mail.body,
        date: new Date().toISOString(),
      };
      recordSent(sent);
      onSent(sent, checked.mail.email);
    } catch {
      setFailed(true);
    } finally {
      setSending(false);
    }
  }

  return (
    <form onSubmit={send} noValidate className="flex h-full flex-col bg-white text-xs">
      <div className="flex h-12 shrink-0 items-center justify-between border-b border-black/10 px-4">
        {onCancel ? (
          <button type="button" onClick={onCancel} className="text-neutral-500 hover:text-neutral-900">
            Cancel
          </button>
        ) : (
          <span />
        )}
        <span className="font-semibold text-neutral-800">New Message</span>
        <button
          type="submit"
          disabled={sending}
          aria-label="Send"
          className="flex items-center gap-1.5 rounded-md px-2 py-1 text-sky-600 hover:bg-sky-50 disabled:text-neutral-400"
        >
          {sending ? "Sending…" : <Send className="size-4" />}
        </button>
      </div>

      {failed && (
        <p role="alert" className="border-b border-black/10 bg-red-50 px-4 py-2 text-red-700">
          {SEND_FAILED.replace(socials.email, "")}
          <a href={`mailto:${socials.email}`} className="underline">
            {socials.email}
          </a>
        </p>
      )}

      <fieldset disabled={sending} className="flex min-h-0 flex-1 flex-col">
        <Row label="To:">
          <span className="text-neutral-800">Jeffrey Yu</span>
        </Row>
        <Field id={`${id}-name`} label="Name:" error={errors.name}>
          <input id={`${id}-name`} autoComplete="name" value={fields.name} onChange={(e) => change("name")(e.target.value)} className={input} />
        </Field>
        <Field id={`${id}-email`} label="Email:" error={errors.email}>
          <input id={`${id}-email`} type="email" autoComplete="email" value={fields.email} onChange={(e) => change("email")(e.target.value)} className={input} />
        </Field>
        <Field id={`${id}-subject`} label="Subject:" error={errors.subject}>
          <input id={`${id}-subject`} value={fields.subject} onChange={(e) => change("subject")(e.target.value)} className={input} />
        </Field>
        {/* bots fill in every field, people never see this one */}
        <input
          ref={honeypot}
          name="website"
          tabIndex={-1}
          autoComplete="off"
          aria-hidden="true"
          className="absolute -left-[9999px] size-px"
        />
        <label htmlFor={`${id}-body`} className="sr-only">
          Message
        </label>
        <textarea
          id={`${id}-body`}
          value={fields.body}
          onChange={(e) => change("body")(e.target.value)}
          aria-invalid={!!errors.body}
          aria-describedby={errors.body ? `${id}-body-error` : undefined}
          className="min-h-0 flex-1 resize-none px-4 py-3 text-neutral-900 outline-none"
        />
        {errors.body && (
          <p id={`${id}-body-error`} className="px-4 pb-2 text-red-600">
            {errors.body}
          </p>
        )}
      </fieldset>
    </form>
  );
}

// lives inside the window, so it resets to the inbox each time mail opens
function Mail() {
  const state = useMail();
  const [box, setBox] = useState<Box>("inbox");
  const [selected, setSelected] = useState<string | null>(null);
  const [composing, setComposing] = useState<Draft | null>(null);

  const rows: Row[] =
    box === "inbox"
      ? inbox.map((e) => ({ ...e, unread: !state.read.includes(e.id) }))
      : box === "sent"
        ? state.sent.map((e) => ({ ...e, from: "To: Jeffrey Yu" }))
        : state.draft
          ? [
              {
                id: "draft",
                from: "Draft",
                subject: state.draft.subject || "(no subject)",
                date: new Date(state.draft.startedAt).toISOString(),
                body: state.draft.body,
              },
            ]
          : [];
  const current = rows.find((r) => r.id === selected) ?? null;

  function open(next: Box) {
    setBox(next);
    setSelected(null);
    setComposing(null);
  }

  function select(row: Row) {
    if (box === "drafts" && state.draft) {
      setComposing(state.draft);
      return;
    }
    setSelected(row.id);
    if (box === "inbox") markRead(row.id);
  }

  function compose(subject?: string) {
    const draft = state.draft ?? newDraft();
    setComposing(subject ? { ...draft, subject } : draft);
  }

  return (
    <div className="flex h-full text-xs">
      <nav aria-label="Mailboxes" className="w-44 shrink-0 border-r border-black/10 bg-neutral-100/80 px-2 pt-12">
        <p className="px-2 pb-1 text-[10px] font-semibold text-neutral-400">Favourites</p>
        <BoxButton icon={<Inbox />} label="Inbox" count={unreadCount(state, ids)} active={box === "inbox"} onClick={() => open("inbox")} />
        <BoxButton icon={<Send />} label="Sent" active={box === "sent"} onClick={() => open("sent")} />
        <BoxButton icon={<FileText />} label="Drafts" count={state.draft ? 1 : 0} active={box === "drafts"} onClick={() => open("drafts")} />
      </nav>

      {composing ? (
        <div className="min-w-0 flex-1">
          <Compose
            initial={composing}
            onCancel={() => setComposing(null)}
            onSent={(sent) => {
              setComposing(null);
              setBox("sent");
              setSelected(sent.id);
            }}
          />
        </div>
      ) : (
        <>
          <section aria-label="Messages" className="flex w-64 shrink-0 flex-col border-r border-black/10">
            <header className="flex h-12 shrink-0 items-center justify-between border-b border-black/10 px-3">
              <div>
                <h2 className="font-semibold text-neutral-900 capitalize">{box}</h2>
                <p className="text-[10px] text-neutral-400">
                  {rows.length} {rows.length === 1 ? "message" : "messages"}
                </p>
              </div>
              <button type="button" aria-label="New message" onClick={() => compose()} className="rounded-md p-1.5 text-neutral-500 hover:bg-neutral-100 hover:text-neutral-900">
                <SquarePen className="size-4" />
              </button>
            </header>
            <ul className="min-h-0 flex-1 overflow-y-auto">
              {rows.length === 0 && <li className="p-6 text-center text-neutral-400">No Messages</li>}
              {rows.map((row) => (
                <li key={row.id}>
                  <button
                    type="button"
                    onClick={() => select(row)}
                    aria-current={row.id === selected}
                    className="relative block w-full border-b border-black/5 py-2 pr-3 pl-6 text-left aria-[current=true]:bg-sky-500 aria-[current=true]:text-white"
                  >
                    {row.unread && <span aria-label="Unread" className="absolute top-3 left-2 size-2 rounded-full bg-sky-500" />}
                    <span className="flex justify-between gap-2">
                      <span className="truncate font-semibold">{row.from}</span>
                      <span className="shrink-0 opacity-60">{mailDate(row.date)}</span>
                    </span>
                    <span className="block truncate">{row.subject}</span>
                    <span className="line-clamp-2 opacity-60">{row.body}</span>
                  </button>
                </li>
              ))}
            </ul>
          </section>

          <article className="min-w-0 flex-1 overflow-y-auto">
            {current ? (
              <Message row={current} box={box} onReply={() => compose(`Re: ${current.subject}`)} />
            ) : (
              <p className="grid h-full place-items-center text-neutral-400">No Message Selected</p>
            )}
          </article>
        </>
      )}
    </div>
  );
}

function Message({ row, box, onReply }: { row: Row; box: Box; onReply: () => void }) {
  return (

      <header className="flex items-start justify-between gap-4 border-b border-black/10 px-5 py-4">

        )}
      </header>

          // paragraphs never reorder, so the index is a stable key
          // biome-ignore lint/suspicious/noArrayIndexKey: see above
          <p key={i}>
            {pieces.map((piece, j) =>
              "href" in piece ? (

              ) : (
                // biome-ignore lint/suspicious/noArrayIndexKey: pieces never reorder
                <span key={j}>{piece.text}</span>
              ),
            )}
          </p>
        ))}
      </div>
    </>
  );
}
